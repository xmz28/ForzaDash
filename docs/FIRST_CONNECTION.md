# 首次连接仪表Wi-Fi

1. 仪表通电，使用iPhone原App连接该仪表。
2. 在iPhone系统中查看这个Wi-Fi的完整名称和密码。请保留大小写，留意I、l、1等相似字符。
3. 在电脑Windows Wi-Fi设置中选择同名网络，输入密码，并保存网络。
4. 打开ForzaDash欢迎页，检测Wi-Fi后进入投屏页。选择自己的仪表网络，软件显示“已连接”后开始测试。

已保存但未连接时，先到Windows Wi-Fi设置连接，再回软件刷新。软件不需要读取密码，也不会替用户切换网络。关闭软件会保留系统Wi-Fi连接。

软件中不内置任何现场仪表密码。

不使用ESP32也能投屏。有ESP32时，可额外使用USB或Wi-Fi其中一种CAN输出；与投屏同时使用时，游戏目标统一填写电脑127.0.0.1，在软件开启相应中继。
